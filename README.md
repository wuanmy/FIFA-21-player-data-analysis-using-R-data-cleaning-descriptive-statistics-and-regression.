# FIFA-21-player-data-analysis-using-R-data-cleaning-descriptive-statistics-and-regression.
**Project Overview**
This project analyzes FIFA 21 player data to compare player attributes across positions and explore relationships between physical characteristics and performance.

**Tools**
R, dplyr, ggplot2, broom

**Methods**
Data cleaning and transformation
Descriptive statistics
Data visualization
Simple and multiple linear regression

**Key Findings**
Player attributes, such as height, weight, dribbling, and agility, vary across positions.
Height has a statistically significant but very weak negative relationship with interceptions.
Weight has a negative relationship with agility.
The multiple regression model explains approximately 77.04% of the variation in agility using six player attributes.

**Limitations**
Regression results show associations but do not prove causation. The findings are based on the FIFA 21 dataset and may not represent current player performance or market conditions.
